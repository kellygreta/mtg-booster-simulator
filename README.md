# ✨ Magic: The Gathering – Booster Pack Simulator ✨

Progetto realizzato per impare meglio React, ho deciso di creare un simulatore di apertura di bustine di **Magic: The Gathering**, sviluppato in React + TypeScript che utilizza le API pubbliche di Scryfall e Bootstrap CSS.

Permette di scegliere un set e aprire un booster pack simulato con la corretta distribuzione delle rarità (1 rara/mitica, 3 uncommon, 10 common, 1 terra/token), calcolando anche il valore totale del pacchetto e facendo un confronto con il suo prezzo.
